# Release Notes for Rumbo Maps

## 1.0.0 - Unreleased

### Added
- Location field with address search, a draggable pin and address parts, working in Matrix and slideouts.
- Maps for one location or many, on OpenFreeMap with no API key, or Google, Mapbox, MapTiler, HERE and Apple with your own key.
- Move from Maps by Ether Creative: every location and field setting in one go, with a dry run, a report and a template check.
- The old Maps Twig values keep working in Lite. Distance queries, `orderBy('distance')`, `.embed()`, `.img()` and `craft.maps.*` keep working in Pro.
- Pro: a store finder with search, "near me", filters and a list, rendered on the server and updated without page reloads.
- Pro: distance search on element queries and GraphQL, on MySQL, MariaDB and PostgreSQL.
- Pro: search insights, with no personal data.
- Privacy mode that loads maps only after consent, with snippets for Cookiebot, CookieYes and Klaro.
- English and Spanish.
